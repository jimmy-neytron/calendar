# Окружение и зависимости

## Поддерживаемое окружение

- WSL 2 (Ubuntu).
- Node.js 24 рекомендуется для разработки.
- Минимальная версия из `package.json`: Node.js 22.18.0.

Проверять активную версию нужно внутри WSL:

```bash
node --version
npm --version
```

## Воспроизводимая установка

Все прямые зависимости закреплены точными версиями в `package.json`, а транзитивные — в `package-lock.json` и `pnpm-lock.yaml`.

```bash
npm install
```

Файл `.npmrc` включает `legacy-peer-deps=true`. Это обход некорректного optional peer-разрешения `@vue/composition-api` для Vue 2 внутри дерева TanStack Query; приложение при этом использует Vue 3. Не применять `--force`, потому что он может скрыть реальные несовместимости.

Vue Router закреплён на ветке 4.6.4: она соответствует используемому API Vue 3 и не добавляет экспериментальные зависимости ветки 5.

## TanStack Query и локальное состояние

TanStack Query отвечает за серверные данные, кэш, повторные запросы и мутации. Локальные store/composables остаются нужны для состояния интерфейса, offline-очереди, текущей сессии и синхронных router guards. Поэтому заменять ими друг друга механически не следует.
