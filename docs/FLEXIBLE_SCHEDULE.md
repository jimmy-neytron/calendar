# Гибкое расписание

В календаре нажмите «Подобрать расписание». Укажите название, календарь,
количество занятий, период (1–8 календарных недель), дни, длительность,
допустимые часы и паузу. Первая неделя может быть неполной.

Предпросмотр допускает выбор другого свободного интервала. Если времени
недостаточно, показано число неразмещённых занятий по неделям; частичное
сохранение требует отдельного согласия. Применение создаёт отдельные события.

В «Мои гибкие занятия» можно закрепить время или подобрать перенос в пределах
исходной недели. Обычные события не переносятся. Подбор учитывает все календари
из доступных событий, а не только текущие визуальные фильтры. Событие на весь
день блокирует дату, событие без окончания занимает час, без времени — весь день.

Кнопка отмены относится к последнему сохранению в текущем сеансе страницы.
Изменённые после сохранения события не перезаписываются при отмене.
При частичной ошибке уже сохранённые события остаются видны и доступны для отмены.
Автоматического продления периода и фонового переноса нет.

## База данных

Перед использованием с Supabase примените миграцию
`supabase/migrations/20260910000000_flexible_calendar_events.sql`.
Она добавляет nullable JSONB-поле `public.events.flexible_rule` и не меняет RLS.
Без миграции сервер отклонит сохранение гибкого события; обычные события
не отправляют новое поле. Миграция должна быть применена до публикации клиента.
